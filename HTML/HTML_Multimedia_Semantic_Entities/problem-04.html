Why Learn HTML?

HTML is the basic language used to structure content on the web. It provides the foundation for webpages before styling and scripting technologies are added.

Learning HTML helps students understand how headings, paragraphs, links, images, tables, forms and other webpage elements are organized.

Important Course Notes

HTML Basics

HTML stands for HyperText Markup Language. It is used to structure content on webpages.

Example: <h1>Hello World</h1>

Students should remember that HTML uses elements and attributes to define webpage content.

Note: HTML is a markup language and not a traditional programming language.

Important Terms

Element: A complete HTML component.

Tag: The markup used to create an HTML element.

Attribute: Additional information provided inside an HTML element.
